# 📚 学习复习助手（单文件版）

一个**记录每日学习/复习内容**的轻量工具，内置**艾宾浩斯遗忘曲线**自动排期复习。
本仓库提供的是**单个 HTML 文件**——下载后双击即用，**完全离线、不需要联网、不需要安装、数据只存在你自己的设备上**。

---

## 🚀 两种使用方式

### 方式一：下载单文件（推荐，离线可用、不受网络限制）
1. 点击本仓库中的 **`学习复习助手.html`** 文件 → 右上角 **Download**（下载原始文件）。
   - 或到 **Releases** 页面下载附件。
2. 下载后**双击**该文件，用浏览器（推荐 Chrome / Edge）打开即可使用。

### 方式二：在线访问（需能访问该域名）
🔗 https://study-review-helper.vercel.app
> 说明：该网址在中国大陆直连可能不稳定；如需随时使用，建议用方式一的离线版。

## ✨ 功能一览

- **✅ 今日学习清单**：记录当天要学什么，勾选完成，自动累计。
- **📕 错题本**：记录错题 + 当时的思路，支持**上传图片**（题目截图等）。
- **🔁 遗忘曲线复习**：新增的错题/笔记自动按 `1 → 2 → 4 → 7 → 15 → 30 天` 间隔安排复习，到期日会在「今日」页提醒你重申。
- **📒 笔记**：带标签、可搜索的知识整理，可勾选"加入复习"。
- **📊 统计**：连续打卡天数、完成率、30 天学习日历热力图等。
- **💾 数据备份**：一键导出/导入全部数据（含图片），方便换设备迁移。

## 🗄 数据是怎么存储的（重要）

- 所有数据保存在**你当前设备、当前浏览器的 localStorage（本地存储）**中，**不会上传到任何服务器**，完全隐私。
- 同一台设备、同一浏览器、同一文件位置打开，**每次都会自动带出你的历史记录**。
- 但以下情况会"看不到"数据（因为它们被视为不同的存储环境）：
  - 换了浏览器（如 Chrome ↔ Edge）
  - 换设备 / 清除了浏览器缓存 / 用了无痕（隐私）模式
  - **移动了该 HTML 文件的存放位置或改了文件名**（请放到固定位置、别改名）
  - 在线网址版 与 本地单文件版，两者数据**互相独立**

### 🛡 如何保证数据不丢 / 如何迁移
1. 定期点「统计 → 💾 数据备份 → **导出**」，会下载一个 `学习备份-日期.json` 文件（含全部数据和图片），存到网盘/U 盘。
2. 换设备或换浏览器时，打开应用 → 「统计 → 💾 数据备份 → **导入**」选中那个 JSON 文件，即可完整恢复。

## ❓ 常见问题

- **双击打不开 / 用记事本打开了？** 右键 → 打开方式 → 选择 Chrome / Edge 浏览器。
- **打开是空白或没样式？** 请用较新版本的 Chrome / Edge / Firefox（IE 不支持）。
- **图片存得下吗？** localStorage 单浏览器上限约 5MB，图片会自动压缩；大量图片请勤用「导出备份」。
- **会不会联网/上传我的内容？** 不会。单文件版完全离线运行，不发起任何网络请求。
